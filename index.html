Introducción

En la programación orientada a objetos, una clase es un molde que sirve para crear objetos. Dentro de ella se definen los datos que va a guardar (atributos) y lo que puede hacer (métodos). Por ejemplo, una clase Estudiante puede tener un nombre y una nota, y un método que muestre esos datos en pantalla.

Al crear una clase es importante decidir qué partes pueden ser usadas desde afuera y cuáles no. Para eso existen los modificadores de acceso, que se explican a continuación con un ejemplo de cada uno.

public class Estudiante
{
    public string nombre;
    public int nota;

    public void MostrarDatos()
    {
        Console.WriteLine("Nombre: " + nombre + " - Nota: " + nota);
    }
}

Modificadores de Acceso

Los modificadores de acceso son palabras reservadas que indican desde dónde se puede usar una clase, un atributo o un método. Sirven para proteger la información y evitar que otras partes del programa la cambien por error. Los más utilizados son public, private y protected.

Public

Un miembro público se puede usar desde cualquier parte del programa, e incluso desde otros proyectos. Se usa para los métodos que la clase ofrece a los demás.

public class Calculadora
{
    public int Sumar(int a, int b)
    {
        return a + b;
    }
}

// En el Main:
Calculadora calc = new Calculadora();
Console.WriteLine(calc.Sumar(5, 3)); // Muestra 8

Private

Un miembro privado solo se puede usar dentro de la misma clase. Si no se escribe ningún modificador en un atributo o método, C# lo toma como privado. Se usa para guardar datos que no deben ser modificados desde afuera.

public class CuentaBancaria
{
    private double saldo = 0;

    public void Depositar(double monto)
    {
        saldo = saldo + monto;
    }

    public double ConsultarSaldo()
    {
        return saldo;
    }
}

// En el Main:
CuentaBancaria cuenta = new CuentaBancaria();
cuenta.Depositar(100);
Console.WriteLine(cuenta.ConsultarSaldo()); // Muestra 100
// cuenta.saldo = 5000;  Esto da error porque saldo es privado

Protected

Un miembro protegido se puede usar dentro de la misma clase y en las clases que heredan de ella, pero no desde afuera. Se usa cuando una clase hija necesita trabajar con los datos de la clase padre.

public class Animal
{
    protected string nombre;

    public Animal(string nombre)
    {
        this.nombre = nombre;
    }
}

public class Perro : Animal
{
    public Perro(string nombre) : base(nombre) { }

    public void Ladrar()
    {
        Console.WriteLine(nombre + " dice: Guau");
    }
}

// En el Main:
Perro perro = new Perro("Bobby");
perro.Ladrar(); // Muestra: Bobby dice: Guau
// perro.nombre = "Max";  Esto da error porque nombre es protegido

Además de estos tres, C# 5 tiene otros dos modificadores menos usados: internal, que permite el acceso desde cualquier parte del mismo proyecto, y protected internal, que combina internal y protected.

Encapsulamiento

El encapsulamiento consiste en ocultar los atributos de una clase, declarándolos como private, y permitir que se lean o se cambien solamente por medio de propiedades o métodos públicos. De esta forma la clase controla sus propios datos y puede evitar que se guarden valores incorrectos.

En C# esto se hace con propiedades, que tienen un get para leer el valor y un set para cambiarlo. En el siguiente ejemplo la edad está oculta y solo se guarda si el valor es válido:

public class Persona
{
    private int edad;

    public int Edad
    {
        get { return edad; }
        set
        {
            if (value >= 0 && value <= 120)
                edad = value;
            else
                Console.WriteLine("Edad no válida");
        }
    }
}

// En el Main:
Persona p = new Persona();
p.Edad = 18;   // Se guarda
p.Edad = -5;   // Muestra "Edad no válida" y no se guarda
Console.WriteLine(p.Edad); // Muestra 18

Cuando no hace falta validar nada, C# 5 permite usar propiedades automáticas, por ejemplo: public string Nombre { get; set; }

Ejemplo Completo

En este ejemplo se usa una sola clase, Vehiculo, que tiene un atributo de cada tipo. La placa es privada y se maneja con encapsulamiento, la velocidad es protegida para que la clase hija Moto pueda usarla, y la marca y el método Acelerar son públicos.

using System;

public class Vehiculo
{
    private string placa;      // Solo la clase Vehiculo la puede usar
    protected int velocidad;   // Vehiculo y sus clases hijas
    public string marca;       // Cualquier parte del programa

    public string Placa        // Encapsulamiento de placa
    {
        get { return placa; }
        set
        {
            if (value != "")
                placa = value;
        }
    }

    public void Acelerar(int cantidad)
    {
        velocidad = velocidad + cantidad;
    }
}

public class Moto : Vehiculo
{
    public void MostrarVelocidad()
    {
        Console.WriteLine("Velocidad: " + velocidad + " km/h");
    }
}

class Program
{
    static void Main()
    {
        Moto moto = new Moto();
        moto.marca = "Yamaha";     // Correcto: es public
        moto.Placa = "AB123CD";    // Correcto: se usa la propiedad
        moto.Acelerar(60);         // Correcto: es public
        moto.MostrarVelocidad();   // Muestra: Velocidad: 60 km/h

        // moto.placa = "XYZ";     Error: placa es private
        // moto.velocidad = 100;   Error: velocidad es protected

        Console.WriteLine(moto.marca + " - " + moto.Placa);
    }
}

Conclusión

Los modificadores de acceso permiten decidir qué partes de una clase pueden ser vistas y usadas por el resto del programa. Usarlos bien, junto con el encapsulamiento, hace que el código sea más seguro, más ordenado y más fácil de mantener, ya que cada clase protege sus propios datos.
